# 🎨 Pro Editor Studio | استودیو پرو

ویرایشگر عکس، رنگ‌یاب و سازنده متن کارتونی — تک‌فایل، بدون وابستگی، کاملاً در مرورگر.

A single-file photo editor, color picker, and cartoon text creator — no dependencies, runs entirely in the browser.

---

## 🇮🇷 فارسی

### ✨ امکانات
- 🖼 **ویرایش عکس**: انتخاب عکس اصلی، افزودن لایه، جابه‌جایی، چرخش و تغییر اندازه لایه‌ها
- 🎛 **فیلترها**: سیاه‌وسفید، محو، منفی، قدیمی
- 🎨 **رنگ‌یاب**: انتخاب رنگ از هر نقطه تصویر + کپی کد HEX + تولید پالت رنگ
- ✏️ **سازنده متن**: چند خط متن، سه فونت (وزیرمتن، بالو، کمیک)، رنگ و سایز دلخواه، سایه قهوه‌ای، دانلود PNG و کپی CSS
- 🌐 **دو زبانه**: فارسی / انگلیسی
- 📱 **ریسپانسیو**: مناسب موبایل و دسکتاپ

### 🚀 استفاده
فایل `index.html` را در مرورگر باز کنید — همین!

### 🛠 تکنولوژی
- HTML5, CSS3, Vanilla JavaScript (بدون هیچ کتابخانه)
- Canvas API برای رنگ‌یاب و خروجی PNG
- Google Fonts (Vazirmatn, Baloo 2)

### 📄 لایسنس
MIT — استفاده آزاد برای همه.

## 🇬🇧 English

### ✨ Features
- 🖼 **Photo Editor**: load a main image, add layers, drag / rotate / resize them
- 🎛 **Filters**: grayscale, blur, invert, sepia
- 🎨 **Color Picker**: pick any color from an image, copy HEX, generate a palette
- ✏️ **Text Creator**: multi-line text, 3 fonts (Vazirmatn, Baloo, Comic), custom color & size, brown shadow, download as PNG, copy CSS
- 🌐 **Bilingual**: Persian / English
- 📱 **Responsive**: works on mobile and desktop

### 🚀 Usage
Open `index.html` in your browser — that's it!

### 🛠 Tech Stack
- HTML5, CSS3, Vanilla JavaScript (zero dependencies)
- Canvas API for color picking and PNG export
- Google Fonts (Vazirmatn, Baloo 2)
